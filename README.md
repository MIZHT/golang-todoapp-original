# TodoApp на Go

Полноценное веб-приложение для управления задачами: REST API на Go, PostgreSQL и веб-интерфейс. Проект демонстрирует разделение приложения на слои и интеграцию HTTP-сервера с хранилищем данных.

## Возможности

- регистрация и работа с пользователями;
- создание и управление задачами;
- получение статистики по задачам;
- веб-страница приложения;
- REST API с версионированием `/api/v1`;
- Swagger-документация;
- PostgreSQL с миграциями;
- конфигурация через переменные окружения;
- запуск сервиса и базы через Docker Compose.

## Технологии

Go, PostgreSQL, pgx, Docker Compose, Swagger, Zap.

## Архитектура

Код разделён на `cmd/todoapp` (точка входа), общие компоненты `internal/core` и функциональные модули в `internal/features`. В модулях отдельно представлены транспорт HTTP, сервисная логика и репозитории.

## Запуск

Нужны Go 1.25+, Docker и Docker Compose.

1. Склонируйте репозиторий и создайте файл `.env` на основе `.env.example`.
2. Заполните параметры PostgreSQL: `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`. Остальные параметры можно оставить со значениями из примера.
3. Запустите базу и приложение:

```bash
docker compose up -d todoapp-postgres
make migrate-up
make todoapp-deploy
```

Приложение слушает порт `5050`. Swagger UI доступен по адресу [http://localhost:5050/swagger/index.html](http://localhost:5050/swagger/index.html).

Для локального запуска Go-приложения используйте `make todoapp-run` после запуска базы и миграций.

## API

Базовый путь API: `/api/v1`. Контракт и доступные маршруты описаны в Swagger UI и файлах каталога `docs`.

## Конфигурация

Основные переменные окружения описаны в `.env.example`: адрес HTTP-сервера, настройки PostgreSQL, тайм-ауты, уровень логирования и часовой пояс.
